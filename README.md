# Lagerverwaltungssystem mit Python und SQLite

## Projektbeschreibung

Dieses Lagerverwaltungssystem ist ein kleines Projekt, mit dem ich über meine bisherigen einfachen Programmierübungen, beispielsweise ein Taxameter oder einen Währungsrechner, hinausgehen wollte. 
Zur Erstellung dieses Programms wurden Python und SQLite genutzt. Diese sollten nach meiner Informationen für einen einfachen Einstieg dienen.
Ich wollte ein Programm entwickeln, das nicht nur zum Üben dient, sondern auch einen praktischen Nutzen haben könnte. 
Gleichzeitig wollte ich lernen, wie Daten dauerhaft gespeichert werden können, weshalb ich mich entschieden habe, SQLite mit einzubinden.
Hiermit wollte ich die Komplexität der Programmierung besser kennenlernen und weitere Erfahrungen sammeln.
Zeitgleich sollte dieses Projekt auch das Interesse für diesen Bereich darstellen und als Zusatz zu meiner Bewerbung dienen.


## Funktionen:
1. Artikel hinzufügen: Neue Artikel können mit einer gewünschten Menge hinzugefügt werden.
2. Bestand erhöhen: Bei bereits vorhandenen Artikeln wird die gewünschte Menge zum Bestand addiert.
3. Artikel entnehmen: Vorhandene Artikel können in ihrer Menge reduziert werden ohne einen negativen bestand zuzulassen.
4. Lagerbestand anzeigen: Der Lagerbestand aller Artikel mit ihrer Menge ist einsehbar
5. Artikel löschen: Artikel sind mitsammt des Bestandes Löschbar
6. Dauerhafte speicherung: Auch nach beenden des Programms bleiben die Lagerbestände erhalten durch die einbindung von SQLite und einer dazugehörigen .db Datei
7. Eingabeprüfung: Um Fehler bei der Eingabe zu verhindern und somit einen absturz wurde mit Schleifen gearbeitet um dieses zu verhindern und eine erneute Eingabe möglich zu machen.


## Installation und Verwendung: 
Vorraussetzung hierfür ist Pyhton-3-Version installiert zu haben. Entwickelt und getestet wurde das Programm mit Python 3.14.4.

1. Projekt aus Github downloaden.
2. Projektordner öffnen.
3. In die Adressleiste des Datei-Explorers "powershell" eintippen und mit Enter bestätigen.
4. Das Programm mit dem folgendem Befehl im Terminal starten: 

   "python Lagerverwaltungssystem.py"
